# REPL Tools

Inline code evaluation for JavaScript, Nushell, DuckDB SQL, and Python.

## Tools

### `bun-repl`

Evaluate JavaScript or TypeScript code inline using `bun -e`.

### `nu-repl`

Evaluate Nushell expressions inline using `nu -c`.

### `duckdb-repl`

Evaluate DuckDB SQL queries inline using `duckdb :memory: -c`. Runs against an in-memory database.

### `python-repl`

Evaluate Python code inline using `python3 -c`.
